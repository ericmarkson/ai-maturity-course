Level 7 — Advanced+

Advanced RAG: Hybrid Search, Reranking, Chunking

Learning objective: The learner can explain how chunk size and overlap affect retrieval quality, and can walk through a hybrid-search-plus-reranking pipeline explaining what each stage filters or reorders.

Definition

Advanced RAG is a set of techniques that improve on basic retrieval-augmented generation by combining multiple search strategies and refining which retrieved chunks actually reach the model. Instead of relying on a single embedding search over arbitrarily-split text, real pipelines tune how documents are chunked, blend keyword and vector search ("hybrid search"), and rerank the combined candidates before anything is handed to the LLM.

How It Works

  • Chunking & Parent-Child Granularity: Fixed-character splitting is cheap but breaks clauses arbitrarily. Structure-aware or semantic chunking splits at paragraph/heading boundaries, while small-to-big (parent-child) retrieval indexes fine-grained child chunks (~150 tokens) for sharp vector matching and returns the wider parent section (~500 tokens) to preserve surrounding qualifiers.
  • Hybrid Search (BM25 + Vector via RRF): Sparse lexical BM25 captures exact product SKUs, error codes (ERR_4092), and rare proper nouns; dense bi-encoder vectors match paraphrases ("airfare policy" ↔ "economy class flights"). Because raw BM25 scores (unbounded) and cosine similarities ([−1, 1]) have incompatible scales, Reciprocal Rank Fusion (RRF) merges rankings via score(d) = Σ 1 / (k + ranki(d)).
  • Cross-Encoder Reranking: Bi-encoders embed query and chunk independently for millisecond top-50 recall, sacrificing token-level cross-attention. A cross-encoder reranker reads each (query, chunk) pair jointly through full self-attention and re-sorts the top-50 candidates so only the highest-precision top-5 enter the LLM prompt.

Worked Example

Trace the travel-policy query "What is the reimbursement limit for flights?" against the candidates below:

  • BM25 keyword search alone: Ranks the 30-day submission deadline passage (kw = 0.60) #1 above the flight-class passage (kw = 0.55) due to literal repetition of "reimbursement".
  • Vector + Reranker pipeline: Dense embeddings score the flight passage higher (vec = 0.82 vs. 0.35), and the cross-encoder reranker scores it 0.95, cleanly promoting the true flight rule to Rank #1 before generation.

Common Pitfall

Summing unnormalized scores or shrinking chunks until qualifiers disappear. Adding raw BM25 scores directly to cosine similarity lets lexical scores drown out semantic matches unless fused with RRF or calibrated weights. Likewise, splitting text into tiny 50-character fragments strips crucial exception clauses ("...unless the trip exceeds six hours"), causing confident wrong answers even when Rank #1 retrieves the right sentence fragment.
