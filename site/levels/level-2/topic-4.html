Classification vs. Regression

Learning objective: Given a new prediction task description, correctly label it as classification or regression and identify what the output would look like.

Definition

Classification predicts which category something belongs to — spam or not spam, cat or dog. Regression predicts a continuous numeric value — tomorrow's temperature, a house's sale price. The type of output you need is what determines which one applies to a given problem.

Subtopics

  • Discrete categories vs. continuous numbers as the output type
  • Binary classification (two classes) vs. multi-class classification
  • Examples spanning both: image labeling (classification), sales forecasting (regression)
  • Why the output type determines which techniques and metrics apply later
