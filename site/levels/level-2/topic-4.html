Classification vs. Regression

Learning objective: Distinguish classification (predicting a discrete category) from regression (predicting a continuous number), separate binary from multi-class classification, and see why output type determines which model family (such as linear vs. logistic regression next) applies.

Definition

Supervised ML problems split into two broad families based on the answer you want back. Classification predicts a discrete category label from a fixed menu of choices (spam vs. not spam; dog vs. cat vs. bird). Regression predicts a continuous number along a number line ($315,000 sale price, 72.4°F, 4.2 delivery days).

How It Works (Buckets vs. Measuring Tape)

  • Classification = Sorting into labeled buckets: With two buckets (fraud vs. valid, pass vs. fail), it's binary classification. With three or more buckets (language detected, tumor grade, email folder), it's multi-class classification.
  • Regression = Reading a measuring tape: Instead of picking a bucket, the model outputs any numeric quantity along a smooth range (and missing by 1 unit hurts less than missing by 100 units).
  • Why this comes first: Before choosing an algorithm or scoring rule, you must know whether you need a category or a number—in the next topic, you'll see how linear regression fits numbers while logistic regression turns lines into category probabilities.

Worked Example: Same Data, Framed Either Way

Suppose a real-estate website has square footage, bedrooms, and neighborhood data for past home sales:

  • Regression framing: "How much will this house sell for?" → output is a number like $428,500.
  • Classification framing: "Will this house sell within 30 days (Yes/No)?" or "Which price tier does it belong to: Budget, Mid-Range, or Luxury?" → output is a category label.

Common Pitfall: Treating Arbitrary Category Codes as Regression Numbers

Never ask a regression model to predict unordered category IDs like 1 = Apple, 2 = Banana, 3 = Cherry. A regression model might predict 2.0 (Banana) as the "average" between Apple and Cherry, which makes no sense! Keep unordered buckets as classification.
