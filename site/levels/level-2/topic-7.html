Level 2 — Novice

Using AI Tools and APIs (ChatGPT, Claude, etc.)

Learning objective: Explain the difference between chatting with an AI assistant through its web app versus calling it through an API, and name two practical limitations to keep in mind when using either.

Definition

Modern AI assistants like ChatGPT and Claude are pretrained models made accessible two main ways: a chat interface for humans to type messages and read replies, and a programmatic API that lets software send requests and get structured responses back. Both routes talk to the same underlying model — the interface is just the door you walk through.

Subtopics

  • Chat interface usage vs. API usage — same underlying model, different access method
  • Context window: what it is and why conversations have a length limit
  • System prompts/instructions vs. user messages (conceptual introduction)
  • Practical limitations: hallucination risk, knowledge cutoffs, no guaranteed factual accuracy
