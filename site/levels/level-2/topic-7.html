Level 2 — Novice

Using AI Tools and APIs (ChatGPT, Claude, etc.)

Learning objective: Compare human chat UIs and developer APIs as two entry points to the same underlying AI model, explain how context windows and system messages shape requests, and anticipate real-world limits like hallucinations and knowledge cutoffs.

Definition

Modern AI tools like ChatGPT or Claude are accessed in two main ways: a chat interface built for people typing in a browser, and a programmatic API built for software sending JSON requests (often paying per input/output token). Both doors talk to the same underlying model—only the packaging and automation controls differ.

How It Works (The Restaurant Front Desk vs. Ordering App)

  • Same kitchen, two ordering channels: Typing into the chat window is like talking to the front counter; calling the API is like sending a structured digital ticket straight from your app's code into the exact same kitchen.
  • System instructions vs. User messages: API payloads separate background rules (role: "system", like "Always reply in 2-bullet JSON") from the user's current request (role: "user").
  • The Context Window = Desk Size: The model can only inspect a bounded amount of text at once (its context window). Every API call is stateless—chat apps appear to "remember" earlier turns because they re-send the whole conversation history inside that desk limit each time!

Worked Example: Why API Calls Include Past Messages

Notice in the exercise's JSON panel that your request sends messages: [{role: "system", ...}, {role: "user", ...}]. On turn 5 of a conversation, a chat app sends turns 1, 2, 3, 4, and 5 together in that array. Once a thread grows past the context window, the oldest messages get trimmed or summarized to fit.

Common Pitfall: Treating Chatbots Like Verified Search Engines

Out of the box, a standalone model predicts likely text from weights frozen at its training knowledge cutoff—it cannot verify private company records or today's breaking news unless connected to web search or file tools, and it can still hallucinate polished, confident-sounding falsehoods.
