Linear and Logistic Regression

Learning objective: Building on the difference between regression and classification, match numeric prediction tasks to linear regression and yes/no probability tasks to logistic regression, and explain how each model's geometry works.

Definition

Linear regression predicts a continuous number by fitting the best straight line (y = w·x + b) through labeled examples. Despite its name, logistic regression is a classification algorithm: it takes that same weighted line and squashes it through an S-shaped curve so the output stays strictly between 0 and 1 as a class probability.

How It Works

  • Linear regression (Straight line): Each input feature gets a weight ("how much does 1 extra square foot raise the price?") plus a starting baseline (intercept). The model slides and tilts the line until the average squared gap between the line and the actual points is as small as possible.
  • Logistic regression (S-curve + threshold): For yes/no problems like pass/fail, a straight line would shoot past 100% or below 0%. Logistic regression bends the line into a smooth S-curve (sigmoid) bounded between 0 and 1, then applies a cutoff (usually 0.5) to decide Yes vs. No.

Worked Example: Study Hours → Score vs. Pass/Fail

Using the same student feature (hours studied):

  • Linear regression: Fits predicted_score = 45 + 6 × hours. Studying 6 hours predicts a numeric exam score of 81.
  • Logistic regression: Maps hours onto an S-curve where 6 hours gives 88% chance of passing—converting to Pass because 0.88 ≥ 0.50, while 2 hours gives 18% chance → Fail.

Common Pitfall: Fooled by the Word "Regression" in Logistic Regression

Beginners often assume logistic regression predicts continuous targets because "regression" is in the name! Remember: linear regression outputs unbounded numbers (house prices), whereas logistic regression outputs probabilities for classification (spam/not spam, default/repay).
