Linear and Logistic Regression

Learning objective: Look at a scatter plot and correctly decide whether linear or logistic regression is the appropriate tool for the prediction task shown.

Definition

Linear regression predicts a continuous number — like a price — by fitting a straight line through the data. Logistic regression predicts a category — like yes/no — by fitting an S-shaped curve that squashes any input into a probability between 0 and 1. Both work by finding weights that best relate the inputs to the output; they just differ in what kind of output they're built to produce.

Subtopics

  • Linear regression: fitting a line to predict a numeric value
  • Logistic regression: converting a line into a probability curve for classification
  • Coefficients/weights as "how much each input matters" (conceptually, no calculus needed)
  • Real-world examples: house price prediction vs. pass/fail prediction
