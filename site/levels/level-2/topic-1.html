Supervised vs. Unsupervised vs. Reinforcement Learning

Learning objective: Given a short description of a new ML problem, correctly classify it as supervised, unsupervised, or reinforcement learning and justify why.

Definition

There are three main ways a machine learning system can learn. In supervised learning, the system studies labeled examples — inputs paired with the correct answer — and learns the mapping between them. In unsupervised learning, there are no labels at all; the system looks for structure or groupings hiding in the data on its own. In reinforcement learning, an agent learns by acting in an environment and getting rewards or penalties for the outcomes of its actions, gradually improving its behavior through trial and error.

Subtopics

  • Supervised learning: labeled data, learning input→output mappings (e.g., email → spam/not spam)
  • Unsupervised learning: no labels, finding structure (e.g., grouping similar customers)
  • Reinforcement learning: agent, environment, reward signal, trial and error (e.g., a game-playing agent)
  • Quick comparison: what kind of data or feedback each approach actually needs
