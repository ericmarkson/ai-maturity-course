LLM Architecture in Depth: Self-Attention, Positional Encoding, Tokenizers

Learning objective: Learner can tokenize a sample sentence using BPE-style rules by hand (or trace through a shown example) and explain why positional encoding is necessary given that attention itself is order-agnostic.

Definition

This is a deeper look under the hood of large language models — how they break text into pieces, keep track of word order, and compute attention efficiently at scale.

How It Works

  • Subword Tokenization (BPE): Byte-Pair Encoding starts from individual bytes or characters and repeatedly merges the most frequent adjacent pair in the training corpus (e.g., t + h → th, th + e → the) up to a fixed vocabulary size (typically 50k–128k). At inference time, those learned merge rules run in strict priority order so frequent words become single tokens while rare words decompose into reusable pieces with zero unknown-word failures.
  • Positional Encoding (Sinusoidal vs. RoPE): Because self-attention operates over a set of embeddings simultaneously, permuting token positions leaves raw attention math unchanged. Early transformers added fixed sinusoidal waves directly to input embeddings; modern LLMs use Rotary Position Embeddings (RoPE), which rotate each token's Query and Key vectors in 2D subspaces by an angle proportional to position m so the resulting dot product depends on relative distance m − n.
  • Scaled Dot-Product Self-Attention & Residual Blocks: Each token projects into Query (Q), Key (K), and Value (V) vectors of dimension dk, computing softmax(QKT / √dk + M) · V, where causal mask M sets future positions to −∞. Dividing by √dk keeps dot products from growing large with width and pushing softmax into near-zero gradients. Pre-norm LayerNorm/RMSNorm and residual skip connections (x + Sublayer(Norm(x))) stabilize gradient flow across deep layer stacks.

Worked Example

Trace two core behaviors inside a decoder block:

  • BPE split vs. merge: On "The unfriendliness", priority rules merge t+h → th → the into 1 token, whereas rarer "unfriendliness" stops matching whole-word merges and splits into subwords like ["un", "friend", "li", "ness"] (4 tokens).
  • Scaling & word order: For "dog bites man" vs. "man bites dog", RoPE rotates Q at position 0 vs. 2 differently relative to "bites" (m − n = −1 vs. +1). With head dimension dk = 64, dividing raw scores by √64 = 8 keeps logits in a moderate range (e.g., [−3, +3] instead of [−24, +24]) so softmax preserves smooth gradient signal.

Common Pitfall

Tokenizer blind spots and quadratic context cost. Because LLMs process subword IDs rather than raw characters, BPE splitting breaks naive character counting (e.g., counting "r"s inside a merged token) and causes non-English scripts or numeric tables to consume 2–4× more tokens per word—raising both latency and cost. Meanwhile, standard self-attention scales O(n2) in compute and KV memory with sequence length n.
