Intro to Reinforcement Learning: Q-Learning and Policy Gradients

Learning objective: Trace one full agent-environment step and temporal-difference Q-table update, contrast value-based Q-learning with policy gradients, and explain how exploration prevents premature convergence.

Definition

Reinforcement learning (RL) optimizes sequential decision-making through interaction: an agent observes state s_t, selects action a_t, receives scalar reward r_t, and transitions to s_{t+1}. Rather than imitating fixed labeled answers, the agent maximizes expected discounted cumulative return G_t = r_t + γ r_{t+1} + γ² r_{t+2} + ….

How It Works

1. Q-Learning (Value-Based): Q-learning estimates the long-term value Q(s, a) of taking action a in state s and acting greedily afterward. After observing (s, a, r, s'), it applies a temporal-difference (TD) update toward the Bellman target: Q(s, a) ← Q(s, a) + α [ r + γ max_{a'} Q(s', a') − Q(s, a) ]. Once Q converges, the policy simply chooses argmax_a Q(s, a).

2. Policy Gradients (Policy-Based): Tabular Q-tables break down in huge or continuous action spaces (e.g., robotic joint torques or token vocabularies). Policy gradient methods skip the Q-table and parameterize a stochastic policy π_θ(a | s) directly, using gradient ascent to increase the probability of actions that yielded higher-than-expected returns.

3. Exploration vs. Exploitation: If an agent always picks its current highest-Q action (exploitation), it can lock onto a weak early path and never discover the real goal. Schedules like ε-greedy pick a random action with probability ε and the greedy action with probability 1 − ε, often annealing ε down once the environment is mapped.

Worked Example: Tracing One Bellman Q-Update

In the 5×5 grid world below, let learning rate α = 0.5 and discount γ = 0.9. Suppose cell (4,3) sits immediately left of GOAL (4,4), and currently Q((4,3), right) = 0.0. When the agent moves right into GOAL, it receives r = +10 and reaches terminal state s' = GOAL (where future value is 0):

  • TD target: r + γ max Q(GOAL, ·) = 10 + 0.9(0) = 10.0
  • TD update: Q((4,3), right) ← 0.0 + 0.5 × (10.0 − 0.0) = 5.0

On a later episode, when the agent reaches neighbor (4,2) and steps right into (4,3) (r = −0.1), its target sees max Q((4,3), ·) = 5.0, updating Q((4,2), right) toward −0.1 + 0.9(5.0) = 4.4. Repeating episodes propagates reward value backward from the goal across the whole maze.

Common Pitfall: Reward Hacking & Zero Exploration

Agents optimize the literal reward function you code, not your intent: poorly shaped positive sub-rewards often cause reward hacking (e.g., spinning in circles to farm intermediate points instead of finishing). Conversely, setting ε = 0 before discovering the goal causes all unvisited states to stay near zero, trapping the agent in arbitrary tie-broken loops.
