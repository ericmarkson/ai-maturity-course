Intro to Reinforcement Learning: Q-Learning and Policy Gradients

Learning objective: Learner can trace one full agent-environment interaction loop (state → action → reward → updated state) for a simple grid-world example and explain how a Q-table entry gets updated.

Definition

Reinforcement learning (RL) trains an agent to make decisions by trial and error, rewarding good outcomes and penalizing bad ones, rather than learning from a fixed labeled dataset the way supervised learning does. The agent repeatedly observes a state, takes an action, receives a reward, and lands in a new state — and over many repetitions it learns which actions tend to pay off in which situations.

Subtopics

  • Agent, environment, state, action, reward loop — the basic cycle every RL algorithm is built on.
  • Q-learning — learning the expected long-term value of taking each action in each state (a "Q-table"), then always picking the highest-value action.
  • Policy gradients — instead of learning action-values, directly learn a strategy ("policy") that maps states to actions, adjusting it to make good actions more likely over time.
  • Exploration vs. exploitation trade-off — the agent must sometimes try random actions (explore) instead of always taking its current best-known action (exploit), or it can get stuck on a mediocre strategy forever.
