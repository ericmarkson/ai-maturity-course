Level 5 — Intermediate+

Hyperparameter Tuning

Learning objective: Learner can explain why tuning on the validation set (not the test set) matters, and can describe the difference between grid search and random search in terms of cost vs. coverage.

Definition

Hyperparameters are the settings you choose before training — like learning rate or batch size — rather than values the model learns on its own from data (those are ordinary parameters/weights). Tuning means systematically searching for the combination of hyperparameters that produces the best model, usually judged by performance on a held-out validation set.

Subtopics

  • Common hyperparameters — learning rate, batch size, number of epochs, network depth/width.
  • Grid search vs. random search vs. Bayesian/automated search — grid search tries every combination on a fixed grid (expensive, exhaustive); random search samples combinations at random (often finds good regions faster with the same budget); Bayesian/automated search uses past results to intelligently pick the next combination to try.
  • Validation-set-driven tuning — and the risk of overfitting to the validation/tuning set itself if you search it too aggressively.
  • Learning rate schedules and early stopping — adjusting the learning rate over time and stopping training once validation performance stops improving.
