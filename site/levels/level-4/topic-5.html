Level 4 — Intermediate

Evaluation Metrics: Precision, Recall, F1, ROC-AUC

Learning objective: Construct a confusion matrix from a small set of predictions vs. true labels and compute precision, recall, and F1 from it by hand, and explain a real-world scenario (e.g. medical screening) where recall matters more than precision, or vice versa.

Definition

"Percent correct" (accuracy) can be badly misleading, especially when one class is rare — a model that always predicts "healthy" can be 99% accurate on a rare-disease dataset while being useless. The standard set of numbers used to judge a classifier more honestly all start from the confusion matrix: how many predictions were true positives, false positives, true negatives, and false negatives.

Subtopics

  • The confusion matrix (true/false positives/negatives) as the foundation
  • Precision: of everything the model predicted positive, how much was actually positive? vs. recall: of everything that was actually positive, how much did the model catch?
  • F1 score as a single number balancing precision and recall (their harmonic mean)
  • ROC-AUC as a threshold-independent measure of how well a model separates the two classes, across every possible decision threshold at once
