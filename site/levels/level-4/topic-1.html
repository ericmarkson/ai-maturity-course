Backpropagation and Activation Functions

Learning objective: Describe the forward-pass/backward-pass cycle in a multi-layer network in your own words, and explain why a network made only of linear operations (no activation functions) would collapse into an equivalent single-layer model.

Definition

Backpropagation is the algorithm that figures out how much each weight in a network contributed to the final error, so gradient descent knows exactly how to adjust it. Activation functions are the non-linear "decision" step applied inside each neuron that let networks learn complex, curved patterns instead of only straight lines.

Subtopics

  • The chain rule, intuitively: blame flows backward from the output error through each layer
  • Forward pass (compute a prediction) vs. backward pass (compute blame/gradients)
  • Common activation functions (sigmoid, ReLU, tanh) and why non-linearity matters
  • Vanishing gradients as a motivating problem for activation function choice
