Level 4 — Intermediate

Backpropagation and Activation Functions

Learning objective: Trace the forward and backward passes through a multi-layer network using the chain rule, explain why removing non-linear activations collapses deep networks into one linear layer, and diagnose vanishing gradients across sigmoid, tanh, and ReLU.

Definition

Backpropagation is the reverse-mode automatic differentiation algorithm that computes how much each weight contributed to the final loss (∂L/∂w) by propagating error signals backward from output to input via the chain rule. Activation functions introduce non-linearity after each weighted sum so stacked layers can bend decision boundaries around complex patterns.

How It Works

1. Forward Pass vs. Backward Pass: Left-to-right, each layer computes a pre-activation z = W a + b and applies an activation a = φ(z), ending in a scalar loss L. Right-to-left, backpropagation multiplies incoming error gradients by the local activation slope φ'(z) and upstream weights, delivering exact weight gradients ∂L/∂W for gradient descent in a single backward sweep.

2. Why Linear Layers Collapse Without Activations: If φ(z) = z everywhere, then two layers compute W_2(W_1 x) = (W_2 W_1) x—mathematically identical to a single matrix W_eff x. No matter how many layers you add, a purely linear network can only model straight lines or flat hyperplanes.

3. Activation Choice & Vanishing Gradients: Classic sigmoid ((0, 1), max derivative 0.25) and tanh ((−1, 1)) flatten at extreme inputs; multiplying derivatives below 0.25 through many layers shrinks early-layer gradients toward zero (vanishing gradients). ReLU (max(0, z)) keeps gradient 1 across all positive values, letting deep nets train cleanly.

Worked Example: Chain Rule Through Two Weights

Suppose input x = 2.0 feeds weight w_1 = 0.5 (z_1 = 1.0), ReLU outputs a_1 = 1.0 (local slope φ'(1.0) = 1), and w_2 = 0.8 predicts ŷ = 0.8 against target y = 1.0 with loss L = ½(ŷ − y)² = 0.02:

  • Output error slope: ∂L/∂ŷ = ŷ − y = 0.8 − 1.0 = −0.2
  • Second-layer gradient: ∂L/∂w_2 = (∂L/∂ŷ) · a_1 = −0.2 × 1.0 = −0.2
  • First-layer gradient (chain rule): ∂L/∂w_1 = (∂L/∂ŷ) · w_2 · φ'(z_1) · x = (−0.2)(0.8)(1)(2.0) = −0.32

Both gradients are negative, telling gradient descent (w ← w − η ∇L) to nudge both w_1 and w_2 upward to raise ŷ closer to 1.0.

Common Pitfall: Saturated Sigmoids & Dying ReLUs

Large initial weights push sigmoid or tanh neurons into their flat tails where derivatives approach zero, stalling training from step one. Conversely, if a giant learning rate drives a ReLU neuron's pre-activation negative for every training example, its derivative stays 0 permanently—a "dead ReLU" that stops updating (variants like Leaky ReLU or GELU prevent hard zero cutoffs).
