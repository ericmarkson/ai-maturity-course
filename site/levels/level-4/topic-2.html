Level 4 — Intermediate

CNNs for Images

Learning objective: Compute a 3×3 convolution response at an image patch by hand, explain how weight sharing reduces parameters compared to dense layers, and trace how stacked convolutions + pooling build hierarchical visual features.

Definition

A Convolutional Neural Network (CNN) processes grid-structured inputs like images by sliding small learned filters (kernels, e.g., 3×3 weights) across height and width. At every position, the kernel takes a dot product with the local pixel patch to emit a feature map—detecting edges first, then textures, parts, and objects across deeper layers.

How It Works

1. Sliding Dot Products: At patch position (r, c), a 3×3 filter multiplies its 9 weights element-by-element against the 9 overlapping pixels and sums them (plus bias). Sliding the kernel across an 8×8 grid without padding produces a 6×6 feature map highlighting wherever that pattern occurs.

2. Weight Sharing Over Dense Connections: Connecting every pixel of a 224×224 RGB image (150,528 inputs) directly to 1,000 dense hidden units requires 150 million weights in one layer—and memorizing a cat in the top-left doesn't help recognize it in the bottom-right. A CNN shares the same 3×3 filter weights across every pixel location (32 filters × 3×3×3 = just 864 weights), detecting patterns anywhere in the image.

3. Hierarchy & Spatial Pooling: Early layers combine raw pixels into edges; deeper layers apply new kernels over earlier feature maps to compose shapes and parts. Pooling (such as 2×2 max-pooling) downsamples spatial size by keeping the strongest response in each small window, cutting compute and adding tolerance to small pixel shifts.

Worked Example: Computing One Vertical-Edge Convolution Value

Apply the 3×3 vertical-edge kernel [[1, 0, −1], [1, 0, −1], [1, 0, −1]] to two patches from a black-left (0), white-right (1) image:

  • Boundary patch [[0, 1, 1], [0, 1, 1], [0, 1, 1]]: row sums (0·1 + 1·0 + 1·−1) = −1 across all 3 rows → total response −3 (strong edge magnitude 3).
  • Uniform white patch [[1, 1, 1], [1, 1, 1], [1, 1, 1]]: row sums (1·1 + 1·0 + 1·−1) = 0 → total response 0 (no vertical edge).

Common Pitfall: Unpadded Shrinking & Over-Aggressive Pooling

Without zero-padding ("same" padding), every 3×3 convolution trims 2 pixels off height and width, and repeated 2×2 pooling quarters spatial area. In deep CNNs, stacking too many unpadded or aggressively pooled layers can erase tiny targets (like distant road signs or small lesions) before the final classification layer ever sees them.
