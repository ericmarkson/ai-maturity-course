RNNs and LSTMs for Sequences

Learning objective: Trace how a recurrent hidden state updates step by step across a sequence, explain why plain RNNs forget early context via vanishing gradients over time, and describe how LSTM gates selectively preserve long-range signals.

Definition

Recurrent Neural Networks (RNNs) process ordered sequences (text, audio, sensor streams) one step at a time, updating a persistent hidden state h_t that summarizes prior steps. LSTMs (Long Short-Term Memory) add a protected memory cell and learned gates (forget, input, output) to choose what past context to retain across dozens or hundreds of steps.

How It Works

1. Recurrent State Updates: At step t, a plain RNN computes h_t = tanh(W_h h_{t-1} + W_x x_t + b)—combining the previous memory h_{t-1} with the current token x_t using the exact same weights at every position.

2. Why Plain RNNs Lose Long-Range Context: Because every step folds old memory through fixed matrix multiplication and squashing, early signals decay exponentially over unrolled time steps—and during backpropagation through time (BPTT), repeated chain-rule multiplications cause gradients from late errors to vanish before reaching early words.

3. LSTM Gates (Selective Memory): An LSTM maintains a separate cell state c_t updated additively: c_t = f_t ⊙ c_{t-1} + i_t ⊙ c̃_t. The forget gate f_t ∈ (0, 1) decides how much prior memory to keep; the input gate i_t decides how much new candidate content to write; and the output gate controls what part of c_t enters the exposed state h_t.

Worked Example: Filler Words vs. Sentiment Carryover

Suppose an RNN reads "The movie was surprisingly great ... [5 neutral clauses] ... overall":

  • Plain RNN: If each step retains 40% of old state (h_t = 0.4 h_{t-1} + 0.6 x_t), after just 4 neutral filler words (x ≈ 0), the "great" signal shrinks to 0.4⁴ = 2.6% of its strength—swamped by the latest neutral word.
  • LSTM: On neutral filler words, the learned forget gate stays open (f_t ≈ 0.95) and the input gate stays nearly shut (i_t ≈ 0.05), letting "great" glide along cell state c_t until a decisive reversal like "but forgettable" opens the gates to overwrite it.

Common Pitfall: Assuming LSTMs Parallelize Like Transformers

While LSTMs tame vanishing gradients far better than plain RNNs, they remain strictly sequential: computing h_t still waits for h_{t-1}. On modern GPU clusters and multi-thousand-token prompts, that step-by-step dependency creates a training bottleneck—which is why Transformer self-attention largely replaced RNNs/LSTMs for large-scale language modeling.
