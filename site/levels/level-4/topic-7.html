PyTorch/TensorFlow Basics

Learning objective: Describe, in order, the standard steps of one training loop iteration (forward pass, loss computation, backward pass, weight update) and explain what "automatic differentiation" saves a practitioner from having to do manually.

Definition

PyTorch and TensorFlow are the two dominant software frameworks that provide the building blocks — tensors, automatic differentiation, prebuilt layers — for defining and training neural networks without writing the underlying math from scratch.

Subtopics

  • Tensors as the core data structure — generalizing numpy arrays into GPU-friendly, differentiable objects
  • Automatic differentiation: the framework computes backpropagation's gradients for you, instead of you deriving and coding the calculus by hand
  • The standard training loop shape: forward pass → compute loss → backward pass → update weights, repeated many times
  • PyTorch's more Python-native, dynamic style vs. TensorFlow/Keras's higher-level, more declarative style — both are illustrative examples, not a prescription for which to use
