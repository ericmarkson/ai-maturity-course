Core Vocabulary: Model, Training, Inference, Dataset, Parameters

Learning objective: Use the five core AI terms—dataset, training, model, parameters, and inference—accurately to describe how an AI system is built and run.

Definition

Every ML system shares five core building blocks: a dataset (the collection of practice examples), training (the heavy process of learning patterns from those examples), the model (the finished, saved software artifact), parameters (the millions or billions of adjustable internal dials stored inside that model), and inference (actually running the finished model to answer brand-new inputs).

How It Works (The Flight School & Soundboard Analogy)

  • Dataset = 10,000 flight simulator recordings: Not one single flight (one data point), but the whole library of examples to practice on.
  • Training = Going through flight school: Expensive, slow, and done upfront (or periodically for updates). The student practices over and over, nudging instincts after every mistake.
  • Model = The certified pilot ready for duty: The finished artifact produced when training wraps up.
  • Parameters = Every fine-tuned dial on a giant audio mixing board: The exact numeric knob settings stored inside the finished model.
  • Inference = Flying a real passenger trip: Fast, repeatable, everyday use on brand-new situations the pilot never saw in school.

Worked Example: Decoding "70-Billion-Parameter Model"

When a tech article announces "We trained a 70-billion-parameter model," it means the saved model file stores 70 billion adjustable numbers (parameters) inside its layers—similar to a soundboard with 70 billion tiny dials. It does not mean the dataset had 70 billion examples, nor does it mean each inference call retrains those dials.

Common Pitfall: Thinking Chatbots Keep Retraining Their Parameters During Your Chat

When you correct an AI chatbot mid-conversation ("No, use bullet points"), you are in the inference phase—the model's internal parameters stay completely frozen! It follows your correction only because your follow-up note sits temporarily in the active conversation window, not because it permanently retrained itself.
