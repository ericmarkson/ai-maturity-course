Level 1 — Beginner

Core Vocabulary: Model, Training, Inference, Dataset, Parameters

Learning objective: Learner can correctly label each step of a simple pipeline diagram (raw data → training → model → inference → prediction) using the five core terms.

Definition

Five words show up in almost every conversation about how ML systems work, and mixing them up is the fastest way to get lost. A dataset is the collection of examples a system learns from. Training is the process of fitting a system to that dataset, adjusting it until it captures the pattern. The model is the artifact — the trained "thing" — that results from training. Parameters are the adjustable internal numbers stored inside that model, the actual values training changed. And inference is what happens afterward: using the already-trained model to make a prediction on new data it hasn't seen before.

Subtopics

  • Dataset (a collection of examples) vs. a single data point within it
  • Training (the fitting process) vs. inference (the "using it" step) — two very different phases
  • Model as the artifact that results from training, separate from the process itself
  • Parameters as the adjustable internal numbers a model learns — introduced conceptually, no math yet

A simple way to keep these straight: training happens once (or periodically, when you retrain), and it's expensive and slow. Inference happens every single time someone uses the finished model, and it's meant to be fast. When you hear "this model has 70 billion parameters," that's a statement about how many adjustable numbers live inside the trained model — not about the size of the dataset it was trained on, and not about how long training took.
