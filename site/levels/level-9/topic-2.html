Mechanistic Interpretability Research

Learning objective: Explain superposition and sparse autoencoder (SAE) dictionary learning, and design a causal activation-patching experiment to isolate load-bearing circuits from correlational artifacts.

Definition

Mechanistic interpretability reverse-engineers neural network weights and activations into human-auditable algorithms ("circuits") and monosemantic internal concepts—using causal interventions rather than purely observational probing to verify which components actually drive a prediction.

How It Works

Two complementary paradigms anchor modern mechanistic interpretability:

  • Superposition & polysemantic neurons: A residual stream of width d (e.g., 4,096) represents m ≫ d real-world concepts by packing sparse features as nearly orthogonal directions (at ~O(exp(d)) capacity via Johnson–Lindenstrauss geometry). Because individual neurons sit on linear combinations of these directions, single neurons fire on unrelated concepts (polysemanticity).
  • Sparse Autoencoders (SAEs) & dictionary learning: An overcomplete SAE expands activation x ∈ ℝd into a wide sparse latent z ∈ ℝm (m = 16k–1M) and reconstructs it via unit-norm feature directions Wdec: 
    z = TopK / ReLU(W_enc · (x - b_dec) + b_enc),   x_hat = W_dec · z + b_dec
L = ||x - x_hat||² + λ ||z||₁
    Because each input uses only ~20–100 active latents, individual SAE features isolate monosemantic concepts (e.g., "Python syntax error", "Golden Gate Bridge", "sycophantic agreement").
  • Causal activation patching: To test whether head L2H1 causally mediates Indirect Object Identification (IOI) or induction, run a clean prompt ("John gave Mary a book because ___" → "she") and a corrupted prompt ("John gave John..." or swapped names), then overwrite L2H1's activation during the corrupted run with the clean run's activation and measure logit recovery.

Worked Example: Tracing an Induction Circuit via Patching

In [A][B] ... [A] → [B] completion, a 2-layer induction circuit pairs an early previous-token head (L1: copies token A's identity into B's residual stream) with a later induction head (L2: queries for A, attends to B whose key carries "preceded by A", and copies B to logits). Patching just those two heads restores >85% of clean logit difference, whereas patching unrelated heads leaves predictions unchanged.

Common Pitfall

Mistaking linear-probe correlation or zero ablation for causal circuits: A linear probe can decode a concept from downstream layers even if the model ignores it, while zeroing out activations pushes the network off-distribution. Always patch with counterfactual/mean activations and verify both sufficiency and necessity—and note that SAE dictionaries remain non-unique across training seeds.
