Novel Architectures: State-Space Models, Mamba, and Beyond

Learning objective: Derive why selective state-space models (Mamba/SSD) achieve O(n) compute and O(1) per-step decoding memory via A, B, C state transitions, and diagnose when fixed-state compression loses exact in-context recall compared to Transformer attention.

Definition

Selective state-space models (SSMs) replace quadratic all-to-all self-attention with a recurrent, input-gated latent state update that runs in linear time O(n) over sequence length and requires constant O(1) memory per generated token at inference, at the cost of compressing past history into a finite hidden state.

How It Works

Whereas classical LTI state-space models (S4) used static dynamics, Mamba makes the discretization step Δ(xt), input projection B(xt), and output projection C(xt) functions of the current token: 

h_t = A_bar(Δ_t) · h_{t-1} + B_bar(Δ_t, x_t) · x_t
y_t = C(x_t) · h_t
  • Selectivity as content-aware gating: Large Δt lets the model reset/overwrite state slots with salient tokens (like a key fact), while small Δt preserves existing state across filler tokens—impossible in time-invariant convolutions.
  • Structured State-Space Duality (SSD / Mamba-2): By restricting A to scalar-times-identity blocks, the linear recurrence can be algebraically rewritten as chunked semi-separable matrix multiplications—unlocking GPU Tensor Cores during parallel prefill while keeping O(1) step cost during autoregressive generation.
  • Hybrid SSM–Attention architectures (Jamba, Zamba): Interleaving ~6–8 SSM layers per 1 full-attention layer preserves most linear throughput while adding attention's lossless exact lookup (associative recall) across arbitrary context positions.

Worked Example: Decoding 128k Context — KV-Cache vs. SSM State

On a 7B model at n = 128,000 tokens (32 layers, d = 4096, GQA-8), full attention stores ~2 · 32 · 1024 · 128,000 · 2 B ≈ 16.8 GB of KV-cache per sequence and reads all 16.8 GB from HBM on every generated token. A pure Mamba layer with state expansion N = 64 holds a fixed 32 · 4096 · 64 · 2 B ≈ 16.8 MB state—1,000× smaller regardless of sequence length—yet begins dropping verbatim copy accuracy once concurrent key-value pairs exceed the effective bit capacity of that 16.8 MB state.

Common Pitfall

Conflating parallel training speed with unbounded in-context memory: Mamba-2/SSD trains rapidly via chunked matmuls, which can disguise its recurrent bottleneck during standard perplexity evals. Always test pure SSMs on multi-query associative recall and needle-in-a-haystack copying before replacing attention on RAG or code-synthesis workloads.
