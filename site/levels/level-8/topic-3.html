Model Safety and Red-Teaming

Learning objective: Classify a given adversarial prompt example into an attack category and propose a concrete mitigation (input filter, permission scope, output check) for it.

Definition

Model safety and red-teaming is the practice of deliberately trying to make an AI system fail, misbehave, or be misused, in order to find and fix weaknesses before real users do. A red team plays the attacker on purpose, so the defenses get hardened before someone does it for real.

Subtopics

  • Attack categories — prompt injection, jailbreaks, data exfiltration, goal hijacking
  • Manual vs. automated red-teaming — scripted adversarial probes, and using other models as attackers
  • Turning findings into fixes — guardrails, filters, policy/prompt changes, regression tests
  • Responsible disclosure — how safety evaluation findings get reported and tracked
