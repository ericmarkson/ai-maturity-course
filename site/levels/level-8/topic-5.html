Mixture-of-Experts Architectures

Learning objective: Explain why an MoE model with N total parameters can be cheaper to run than a dense model with N parameters, and describe what the router/gating network does.

Definition

Mixture-of-experts (MoE) is a model architecture with many specialized "expert" sub-networks, where only a small subset is activated for any given input — keeping compute cost low while total model capacity stays high. A router/gating network decides, per token, which experts get to process it.

Subtopics

  • Experts and the router — a gating network decides which experts run per token
  • Sparse activation — activating only a few experts is cheaper than a dense model of the same total size
  • Load balancing — spreading tokens evenly across experts, and the failure mode of a few experts dominating routing
  • Tradeoffs — more total parameters/knowledge vs. routing complexity and memory footprint
