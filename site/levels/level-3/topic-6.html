Level 3 — Advanced Beginner

Gradient Descent

Learning objective: Trace the gradient-descent update rule θ_new = θ_old − η · ∇L, predict how tiny vs. oversized learning rates behave on a loss curve, and distinguish local minima from global minima on non-convex surfaces.

Definition

Gradient descent is the iterative optimization algorithm that trains neural networks and regression models by stepping downhill on a loss landscape. At each step, it measures the local slope (gradient ∇L, pointing uphill) and subtracts η · ∇L from the current parameters—moving opposite the uphill slope toward lower error.

How It Works

1. Why Subtract the Gradient: If increasing parameter x makes loss rise (positive slope g > 0), subtracting η · g moves x left (downhill). If slope is negative (g < 0), subtracting a negative nudges x right (still downhill). Near a valley bottom, slope shrinks toward zero so steps naturally settle.

2. Learning Rate η Dynamics: A tiny η takes safe steps yet crawls slowly and burns compute. A well-tuned η descends briskly and settles at the bottom. An excessive η leaps past the valley floor onto steeper ground on the opposite wall—oscillating wildly or diverging upward.

3. Local Minima, Saddle Points & Epochs: Because gradient descent only feels the local slope directly underfoot, a bumpy landscape can trap parameters inside a shallow nearby dip (a local minimum) while a deeper global minimum sits elsewhere. Training repeats updates across thousands of mini-batches; one complete pass through the training dataset is called an epoch.

Worked Example: Good Step vs. Overshoot on L(x) = 0.5 x²

For L(x) = 0.5 x², the slope (gradient) is simply g = x, and the true minimum sits at x = 0. Start at x₀ = 4.0 (initial loss 8.0):

  • Steady learning rate (η = 0.2): x₁ = 4.0 − 0.2(4.0) = 3.2 (loss drops to 5.12) → x₂ = 3.2 − 0.2(3.2) = 2.56 (loss 3.28), steadily converging to 0.
  • Oversized learning rate (η = 2.5): x₁ = 4.0 − 2.5(4.0) = −6.0 (loss jumps UP to 18.0!) → x₂ = −6.0 − 2.5(−6.0) = +9.0 (loss explodes to 40.5—diverging!).

Common Pitfall: Stopping at Zero Gradient Without Checking Validation Loss

Gradient descent halts whenever ∇L ≈ 0—which occurs at flat saddle points and shallow local minima just as easily as at good minima, and on unscaled features narrow canyons make standard gradient descent bounce side-to-side. Scaling inputs, adding momentum (like Adam), and decaying the learning rate help navigate tricky surfaces cleanly.
