k-NN and k-Means Clustering

Learning objective: Predict a query point's class using k-NN majority voting, explain how changing k shifts the bias–variance trade-off, and trace the assignment/update loop of unsupervised k-means clustering.

Definition

k-NN (k-Nearest Neighbors) is a supervised algorithm that classifies a query by measuring straight-line distance to labeled examples and taking the majority vote of its k closest neighbors. k-means is an unsupervised algorithm that discovers k compact groups inside unlabeled points by alternating nearest-centroid assignment and centroid averaging.

How It Works

1. Distance as Similarity: Both algorithms rely on Euclidean distance d = √((x₁ − x₂)² + (y₁ − y₂)²) (or Manhattan/cosine distance). Because raw coordinates determine closeness, both require features on comparable scales.

2. Choosing k in k-NN (Bias–Variance Trade-Off): With k = 1, a query copies its single nearest neighbor—creating jagged boundaries vulnerable to individual noisy labels (high variance). Raising k (e.g., k = 7) averages over a wider neighborhood, smoothing out outliers; pushing k too high blurs real local clusters into the global majority class (high bias).

3. The k-Means Loop: Initialize k centroids, then repeat two steps until centroids stabilize: (1) Assign every point to its nearest centroid; (2) Update each centroid to the mean (x̄, ȳ) of all points assigned to it.

Worked Example: How One Stray Point Flips k = 1 vs. k = 5

Suppose a stray Class B label sits at (100, 100) inside a neighborhood of four Class A points around (90–115, 95–110). A new query arrives at (102, 101):

  • At k = 1: The closest point is the single stray Class B point (distance ~2.2) → predicts Class B (fooled by noise!).
  • At k = 5: The 5 nearest neighbors include that 1 stray B point plus 4 surrounding Class A points → votes 4 A vs. 1 B → Class A.

Common Pitfall: Unscaled Axes & Poor k-Means Starting Centroids

Because Euclidean distance squares coordinate differences, one large-scale feature (like salary in dollars vs. age in years) silently dominates nearest-neighbor and k-means calculations unless columns are normalized first. In k-means, random initial centroids can also trap clusters in bad local optima—always run multiple smart restarts (k-means++) and keep the lowest total within-cluster distance.
