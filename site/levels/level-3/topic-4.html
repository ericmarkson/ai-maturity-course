Level 3 — Advanced Beginner

Feature Engineering and Data Cleaning

Learning objective: Given a small messy dataset (missing values, mixed scales, text categories), you should be able to propose a specific cleaning/encoding step for each problem you spot, and explain why an un-normalized feature can distort a distance-based model like k-NN.

Definition

Feature engineering and data cleaning is the practice of transforming raw, messy data into the clean, informative inputs a model actually needs to learn well. Real data almost never arrives ready to feed into a model — it has blanks, inconsistent spellings of the same value, and numeric columns on wildly different scales, all of which can quietly wreck a model's performance if left as-is.

Subtopics

  • Handling missing values (drop, impute) — filling a blank with a sensible value (like the column's mean) instead of leaving a hole a model can't process.
  • Encoding categorical variables (one-hot, ordinal) — turning text categories into numbers a model can use, without implying a false order between them.
  • Scaling/normalizing numeric features — putting columns on comparable scales so no single feature dominates just because its numbers happen to be bigger.
  • Creating new features from existing ones — e.g. combining a date field into a more informative "day of week."
