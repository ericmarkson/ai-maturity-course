Level 3 — Advanced Beginner

Decision Trees and Random Forests

Learning objective: You should be able to trace a small decision tree by hand given a set of yes/no questions and a data point, predict its output, and explain in one sentence why a forest of trees tends to generalize better than any single tree.

Definition

A decision tree is a flowchart of yes/no questions that splits data into groups to make a prediction — "is age > 30? if yes, ask another question; if no, ask a different one" — until it reaches a final answer. A random forest trains many slightly different trees (each seeing a random slice of the data) and lets them vote together, which tends to produce a far more reliable prediction than any single tree alone.

Subtopics

  • How a tree picks its splits (impurity/information gain, intuitively) — at each step, the tree looks for the question that best separates the classes.
  • Overfitting in a single deep tree vs. pruning — a tree that asks too many narrow questions memorizes noise instead of learning general patterns.
  • Ensembles: bagging and why averaging many trees reduces variance — many imperfect, differently-biased trees can average out to something more stable.
  • Feature importance as a byproduct of tree-based models — which questions the trees relied on most tells you which features mattered most.
