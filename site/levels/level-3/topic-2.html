Level 3 — Advanced Beginner

Decision Trees and Random Forests

Learning objective: Trace how a decision tree selects threshold splits using impurity reduction, diagnose overfitting in overly deep trees, and explain how random forests reduce variance via bootstrap aggregation and feature subsampling.

Definition

A decision tree predicts outcomes by routing inputs down a hierarchy of threshold tests (e.g., income > 60k?), partitioning feature space into axis-aligned boxes whose leaves return a majority class or mean value. A random forest trains hundreds of diverse decision trees on random data slices and feature subsets, averaging their votes to cancel out individual tree variance.

How It Works

1. Choosing Splits via Impurity Reduction: At each node, the tree evaluates candidate thresholds across features and picks whichever split yields the purest child groups—measured by Gini impurity or entropy (information gain). A box holding 10 Blue / 0 Orange has zero impurity; a 50/50 split has maximum impurity.

2. Deep Tree Overfitting & Pruning: Unconstrained trees keep splitting until every leaf contains 1–2 samples—memorizing outliers and noisy training quirks. Capping max_depth or min_samples_leaf (pruning) forces broader, more general leaves.

3. Bagging & Feature Subsampling in Random Forests: If every tree saw identical rows and columns, all trees would look alike and make identical mistakes. Random forests use bagging (sampling training rows with replacement per tree) plus considering only a random subset of features at each split—decorrelating the trees so ensemble voting suppresses variance and reveals feature importance.

Worked Example: Tracing a Depth-2 Credit Screening Tree

Suppose a depth-2 tree uses Split 1: income > $55k and Split 2: credit_score > 680:

  • Applicant ($70k, score 710) takes Right → Right into a leaf holding 18 Paid / 2 Defaulted → predicts Approve (90%).
  • Applicant ($70k, score 610) takes Right → Left into a leaf holding 4 Paid / 11 Defaulted → predicts Decline.

Every rule corresponds to a crisp horizontal or vertical rectangle—easy to explain, yet brittle if carved too deeply around single edge cases.

Common Pitfall: Expecting Trees to Extrapolate Trends

Because every leaf simply outputs the average or majority class of training points inside its boundary box, a decision tree or random forest cannot extrapolate beyond the range seen in training. If training house sizes stopped at 3,000 sq ft, a random forest predicts roughly the same price for a 6,000 sq ft mansion as for a 3,000 sq ft house—use linear/trend components when forecasting outside observed bounds.
