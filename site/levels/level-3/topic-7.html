Loss Functions

Learning objective: Compute MSE, MAE, and binary cross-entropy values from predictions, contrast how MSE vs. MAE react to large outliers, and explain why classifiers optimize cross-entropy rather than squared error.

Definition

A loss function compresses a model's prediction error across a batch or dataset into a single scalar score that gradient descent minimizes. Choosing the loss defines the exact shape of the loss landscape: continuous regression tasks typically minimize MSE or MAE, whereas probability classifiers minimize cross-entropy.

How It Works

1. Regression Losses (MSE vs. MAE): Mean Squared Error averages (ŷ − y)² across examples—squaring errors so big misses hurt quadratically more than small ones and yielding smooth slopes down to 0. Mean Absolute Error averages |ŷ − y|, treating every extra unit of error linearly so a few wild outlier labels don't pull the whole model off-center.

2. Classification Loss (Cross-Entropy): When predicting a category probability p ∈ (0, 1) for a true positive (y = 1), binary cross-entropy scores −log(p) (and −log(1 − p) when y = 0). Confidently wrong predictions (e.g., predicting p = 0.01 when truth is 1) blow up toward infinity, supplying strong gradients to fix overconfident mistakes.

3. Single-Example Loss vs. Average Dataset Loss: Training computes each example's penalty and minimizes the mean loss over a batch or dataset—so every gradient step moves the landscape height down across examples together.

Worked Example: Comparing Error Penalties

Suppose true house price is 6 (hundred thousand):

  • Prediction 4 (error = 2): MAE = 2, MSE = 2² = 4.
  • Prediction 2 (error = 4, twice as bad): MAE = 4 (2× penalty), while MSE = 4² = 16 (4× penalty).
  • Classification (y = 1): Predicting p = 0.90 incurs −log(0.90) ≈ 0.105; predicting p = 0.05 incurs −log(0.05) ≈ 2.996 (~28× harsher!).

Common Pitfall: Using MSE on Sigmoid Classifiers or Uncleaned Outliers

Pairing MSE with a sigmoid classifier flattens gradients whenever a neuron is confidently wrong (because σ'(z) ≈ 0 at extreme predictions), slowing learning—cross-entropy cancels that saturation cleanly. Meanwhile, using MSE on noisy regression labels with occasional data-entry typos (e.g., $50M instead of $500k) skews predictions heavily toward the typo unless outliers are cleaned or MAE/Huber loss is used.
