Level 3 — Advanced Beginner

Loss Functions

Learning objective: Given a predicted value and a true value, you should be able to compute a simple squared-error loss by hand, and explain why classification tasks need a different kind of loss function than regression tasks.

Definition

A loss function is a single number that measures how wrong a model's prediction is, which gradient descent then tries to minimize. Different tasks call for different losses — the "right" way to score a mistake on a house-price prediction is not the same as the right way to score a mistake on a spam/not-spam decision.

Subtopics

  • Regression losses vs. classification losses — regression tasks (predicting a number) commonly use something like mean squared error, while classification tasks (predicting a category) commonly use cross-entropy — conceptually different ways of scoring a mistake.
  • Why the choice of loss shapes what "good" means — a loss that squares the error punishes big misses much harder than small ones, while a loss that takes the absolute value treats every unit of error the same; picking a loss is picking what kind of mistake you care most about avoiding.
  • Loss on one example vs. average loss over a dataset — you can compute loss for a single prediction, but training actually minimizes the average loss across every example in the training set.
  • Connecting loss to the "downhill" surface — the loss function is exactly what defines the height of the loss landscape from the gradient descent lesson; gradient descent is just walking downhill on the surface this function draws.
