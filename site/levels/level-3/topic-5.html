Perceptrons and Basic Network Architecture

Learning objective: Compute a perceptron's weighted sum and threshold decision by hand, interpret how weights and bias orient and shift a linear decision boundary, and explain why solving XOR requires stacking multiple layers with non-linearities.

Definition

A perceptron is the foundational artificial neuron: it computes a weighted sum of its inputs plus a bias, z = w₁x₁ + w₂x₂ + … + b, and outputs a decision when z crosses zero. Connecting layers of neurons where one layer's outputs feed the next forms a multi-layer perceptron (MLP) capable of carving out curved, non-linear boundaries.

How It Works

1. Geometry of Weights & Bias: Setting w₁x + w₂y + b = 0 defines a single straight separating line in 2D (or flat hyperplane in higher dimensions). Weights (w₁, w₂) control the tilt/angle of that line and which side fires positive, while bias b slides the boundary away from the origin (0, 0).

2. The Linear Separability Wall (XOR): Because a single perceptron only cuts space with one straight line, any pattern whose same-class examples occupy diagonally opposite corners—such as XOR—is mathematically impossible for a single layer to separate cleanly.

3. How Hidden Layers Solve XOR: A hidden layer deploys multiple neurons simultaneously—each drawing its own straight cut (e.g., Neuron A checks x + y > 0, Neuron B checks x + y < 2). An output neuron then combines those hidden signals (AND-ing or weighting them with non-linear activations) to isolate diagonal stripes or curved regions.

Worked Example: Computing a Perceptron Decision by Hand

Let weights be w₁ = 1.5, w₂ = −1.0, and bias b = −1.0, firing 1 whenever z ≥ 0:

  • Input (x = 2, y = 1): z = 1.5(2) + (−1.0)(1) + (−1.0) = 3.0 − 1.0 − 1.0 = +1.0 ≥ 0 → predicts 1.
  • Input (x = 1, y = 2): z = 1.5(1) + (−1.0)(2) + (−1.0) = 1.5 − 2.0 − 1.0 = −1.5 < 0 → predicts 0.

Common Pitfall: Omitting Bias or Using Hard Step Thresholds in Deep Nets

Dropping the bias term (b = 0) forces every separating line through (0, 0), failing whenever positive and negative clusters both lie on one side of the origin. Also, a hard 0/1 step function has zero slope everywhere except at zero—so multi-layer networks replace hard steps with smooth, differentiable activations (like sigmoid or ReLU, covered in Level 4) so gradient descent can train hidden layers.
