Python for ML: NumPy and Pandas

Learning objective: Explain why vectorized NumPy operations outpace Python loops, trace row-filtering and groupby aggregations on a pandas DataFrame, and prepare clean 2D numeric feature arrays for downstream ML models.

Definition

NumPy provides fast, contiguous, homogeneous multi-dimensional arrays (ndarray) and vectorized math routines. pandas layers labeled columns and row indices on top of NumPy arrays via the DataFrame—giving you spreadsheet-like filtering, joining, missing-value handling, and grouped aggregations on tabular data before converting clean arrays into ML inputs.

How It Works

1. Vectorization vs. Python Loops: Standard Python lists hold pointers to boxed objects, forcing the interpreter to check data types on every iteration of a for loop. A NumPy array stores raw numbers of one fixed type side-by-side in memory, letting a single expression like scores * 1.05 run in compiled C/SIMD code—commonly 20–100× faster on large arrays.

2. Filtering & Grouping in DataFrames: A pandas DataFrame pairs named columns (mixing text categories and numbers) with boolean indexing—e.g., df[df["category"] == "Vision"]—and split-apply-combine aggregations like df.groupby("category")["score"].mean().

3. Reshaping for ML APIs: Scikit-learn and neural frameworks expect numeric feature matrices X of shape (n_samples, n_features) and target vectors y of shape (n_samples,), typically loaded from CSV/Parquet files and extracted with df[["hours", "attendance"]].to_numpy().

Worked Example: Slicing & Reshaping Tabular Data

Starting from a CSV loaded as df (10 student rows, columns Name, Category, Score, Hours): 

vision_df = df[df["Category"] == "Vision"]         # 4 matching rows
mean_score = vision_df["Score"].mean()             # 88.25 across those 4 rows
X = vision_df[["Hours"]].to_numpy()                # 2D shape (4, 1) for a model

Notice that double brackets [["Hours"]] preserve a 2D matrix shape (4, 1) expected by ML estimators, whereas single brackets ["Hours"] return a 1D Series of shape (4,).

Common Pitfall: Silent Broadcasting & Slow Row Loops

Adding a 1D row vector (4,) to a 2D column vector (4, 1) triggers NumPy broadcasting, silently producing a 4×4 matrix instead of raising an error—always verify .shape before arithmetic. Likewise, looping row-by-row with df.iterrows() discards vectorization speedups; prefer vectorized column operations instead.
