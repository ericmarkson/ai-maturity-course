Level 3 — Advanced Beginner

Python for ML: NumPy and Pandas

Learning objective: You should be able to look at a small tabular dataset and describe, in plain language, how you'd select a subset of rows, compute a column-wise statistic, and reshape the data into the form a model expects — without writing actual Python code.

Definition

NumPy and pandas are the two foundational Python libraries that let you store, reshape, and crunch numerical data efficiently instead of writing raw loops. NumPy gives you fast arrays and vectorized math; pandas builds on top of that to give you DataFrames — spreadsheet-like tables with labeled rows and columns that you can filter, sort, group, and summarize with a single line of code.

Subtopics

  • Arrays and vectorized operations (numpy) vs. Python lists — why applying an operation to an entire array at once is dramatically faster than looping element by element.
  • DataFrames, rows/columns, indexing and filtering (pandas) — treating a dataset like a table you can slice by row, column, or condition.
  • Basic aggregation and grouping (mean, sum, groupby) — collapsing many rows into summary statistics, optionally split by category.
  • Reading/writing tabular data (CSV-like structures) — the everyday format most real-world datasets arrive in.
